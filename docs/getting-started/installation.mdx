Reliant is a cloud service, so there are three ways in: use it in the browser with nothing to install, install the desktop app, or install the `reliant` command line tool to run a daemon on a machine of your own. Whichever you pick, you sign in to the same account, and what you see is the same.

## Web app

Open [app.reliantlabs.io](https://app.reliantlabs.io) and sign in. There is nothing to download. If you choose a Reliant cloud machine during setup, this is all you need, and it works from any device with a browser, including your phone.

## Desktop app

The desktop app is the same interface in its own window. It also lets you use your own computer as the machine that runs your agents' tools (read files, run commands) without any extra setup, because the app starts a daemon for you.

### Requirements

| Platform | Requirement |
|----------|-------------|
| **macOS** | macOS 12 (Monterey) or later, Apple Silicon or Intel |
| **Windows** | Windows 10 or 11, x64 or ARM64 |
| **Linux** | x86_64 or ARM64, as an AppImage or a `.deb` package (Debian, Ubuntu) |

You also need an internet connection, because Reliant's servers run the agent loop and call the model.

### Homebrew (macOS only)

```bash
brew install --cask reliant-labs/reliant/reliant
```

Or add the tap first, then install:

```bash
brew tap reliant-labs/reliant
brew install --cask reliant
```

Homebrew picks the right build for your Mac (Apple Silicon or Intel). The cask is for macOS only; on Windows and Linux use the direct downloads below. If you don't have Homebrew, see [brew.sh](https://brew.sh).


## Command line tool

The `reliant` CLI is what runs a daemon on a machine you own, such as a workstation, a server or a Raspberry Pi, so your agents can work there. You don't need it if you only use the web app or a Reliant cloud machine. The desktop installs include it and put it on your `PATH`: the Debian package and Windows installer do so at install time, and the other desktop installs do it the first time you open the app. Run `reliant --version` to check, then `reliant daemon start` to connect the machine to your account. See [Your own computer](/machines/your-computer) for the full walkthrough.

Reliant's source is on [GitHub](https://github.com/reliant-labs/reliant) under the Business Source License 1.1 (see the [License FAQ](/license-faq)). To build it yourself, follow [CONTRIBUTING.md](https://github.com/reliant-labs/reliant/blob/main/CONTRIBUTING.md).

## After installing

Launch Reliant and sign in. Setup walks you through choosing a machine, a model, and your first project; the [Quick Start](/getting-started/quick-start) follows it step by step.

## Updating

The desktop app updates itself. To check manually, use **Reliant → Check for Updates**. With Homebrew:

```bash
brew upgrade --cask reliant
```

The web app is always current. 

## Uninstalling

### Homebrew

```bash
brew uninstall --cask reliant

# Also remove settings:
brew uninstall --cask reliant --zap
```

### macOS Manual

1. Quit Reliant
2. Drag from Applications to Trash
3. Remove settings (optional):

```bash
rm -rf ~/Library/Application\ Support/reliant
rm -rf ~/Library/Logs/Reliant
```

### Windows

1. Quit Reliant
2. Settings → Apps → Installed Apps → Reliant → Uninstall
3. Remove settings (optional): Delete `%APPDATA%\Reliant`

### Linux

1. Quit Reliant
2. Delete the AppImage file, or remove the package with your package manager if you installed the `.deb`
3. Remove settings (optional):

```bash
rm -rf ~/.config/reliant
rm -rf ~/.local/share/reliant
```

Your projects and code remain untouched.
