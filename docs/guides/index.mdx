Each task guide does one job, in steps you can run and a final step that checks the result. The **How it works** deep dives explain the design underneath: what happens, why it was built that way, and what it does not do. The guides are grouped by pillar, in the order most projects meet them.

## Agents & workflows

Put agents to work on your repository: run the built-in workflows, write your own, and start them from schedules, webhooks and GitHub events. The [workflows overview](/workflows/overview) is the reference.
