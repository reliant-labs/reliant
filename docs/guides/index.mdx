Each task guide does one job, in steps you can run and a final step that checks the result. The **How it works** deep dives explain the design underneath: what happens, why it was built that way, and what it does not do. The guides are grouped by pillar, in the order most projects meet them.

## Agents & workflows

Put agents to work on your repository: run the built-in workflows, write your own, and start them from schedules, webhooks and GitHub events. The [workflows overview](/workflows/overview) is the reference.

### Built-in workflows

- [Autopilot](/guides/autopilot): five workflows that review pull requests, work issues, answer review feedback and triage alerts. None merge
- [Get It Right](/guides/get-it-right): an implement, check and review loop for changes in a complex codebase
- [Best of Three](/guides/best-of-three): three agents implement the same task, and a reviewer picks or combines the best
- [Create a Workflow](/guides/create-a-workflow): describe what to automate, and Reliant builds and tests the workflow with you

{/* guides: agents-and-workflows */}

### Review and fix code

- [Review every pull request with an AI agent](/guides/workflows/review-pull-requests-with-ai): turn on Autopilot PR review, then read, skip or re-run its review
- [Add an AI security code review to every pull request](/guides/workflows/ai-security-review-pull-requests): findings by severity, with evidence and a fix
- [Have an agent address pull request review comments](/guides/workflows/agent-addresses-review-comments): it changes the code, pushes and replies in each thread
- [Turn labelled GitHub issues into pull requests with AI](/guides/workflows/github-issues-to-pull-requests): label an issue `agent:ready` and get a tested pull request
- [Turn production alerts into GitHub issues with an on-call agent](/guides/workflows/production-alerts-to-github-issues): one investigated issue per new alert or error
- [Go from a production error to a reviewed fix](/guides/workflows/production-error-to-fix): from an on-call issue to a merged, deployed fix, with a person at each gate

### Write and test workflows

- [Write your first multi-agent workflow in YAML](/guides/workflows/first-multi-agent-workflow): a planner, an implementer and a reviewer that sends work back
- [Loop an AI agent until your tests pass](/guides/workflows/run-tests-until-they-pass): fix, test and retry, with a cap on attempts
- [Require human approval before an AI agent acts](/guides/workflows/require-human-approval): approval nodes, timeouts and questions mid-run
- [Run parallel coding agents in separate git worktrees](/guides/workflows/parallel-agents-git-worktrees): two agents at once, a join, and a reviewer that picks one
- [Delegate work to parallel AI sub-agents](/guides/workflows/delegate-to-sub-agents): a shared plan, a briefing file, then steer, stop and combine

- [Reclaim worktree disk space and restore reclaimed work](/guides/machines/reclaim-restore-worktrees): free idle worktrees and restore one from its capture

### Models

- [Use your Claude or ChatGPT subscription with Reliant](/guides/machines/use-claude-or-chatgpt-subscription): run agents on a plan you already pay for instead of API credit
