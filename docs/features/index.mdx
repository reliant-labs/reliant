Reliant combines chat-based coding assistance with workflow orchestration, workspace isolation, and configurable tooling.

## In this section

- [Worktrees & Workspaces](/features/worktrees) — work on multiple branches in parallel
- [Threads](/features/threads) — understand conversation structure and thread modes
- [Branching](/features/branching) — explore alternate paths without losing context
- [Processes](/features/processes) — run commands discovered from your project
- [Git Integration](/features/git-integration) — GitHub CLI, branch workflows, and PR creation
- [Skills](/features/skills) — install and use `SKILL.md`-based skills

## What this section covers

These pages focus on the parts of Reliant that connect the assistant to your real development environment:

- isolated workspaces via git worktrees
- thread management for multi-agent workflows
- branch-based conversation recovery and experimentation
- project command discovery and execution
- source-control integration
- portable, discoverable skills
