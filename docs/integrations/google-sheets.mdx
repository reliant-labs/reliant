The Google Sheets integration works as the Google account you connect, on any spreadsheet that account can open.

## Connecting

You sign in with Google and approve access to your spreadsheets (seeing, editing, creating and deleting them), plus the basic sign-in permissions that tell Reliant which Google account you are. The connection is labelled with the account's email address. If Google stops accepting the stored sign-in, the connection needs to be reconnected; reconnecting asks for consent again so Google issues a fresh one.

## Actions

Ranges are written in A1 notation, usually with the tab name: `Sheet1!A1:D20`. A tab name with spaces needs single quotes: `'Q4 pipeline'!A1:C5`. A spreadsheet is identified by its id, the long token in its URL between `/d/` and `/edit`.

| Action | What it does |
|--------|--------------|
| `google_sheets/spreadsheet.create@1` | Create a spreadsheet from a `title`, optionally with one tab per name in `sheet_names`. Returns the `spreadsheet_id`, its URL and its tabs |
| `google_sheets/spreadsheet.get@1` | A spreadsheet's title and tabs (name, `sheet_id`, size). Never includes cell data |
| `google_sheets/values.get@1` | Read one `range`. `value_render_option` is `FORMATTED_VALUE` (the default), `UNFORMATTED_VALUE` or `FORMULA`; `major_dimension` is `ROWS` or `COLUMNS` |
| `google_sheets/values.batch_get@1` | Read several `ranges` of one spreadsheet in one call |
| `google_sheets/values.update@1` | Write `values` (a list of rows) at a `range`, overwriting what is there. `value_input_option` is `USER_ENTERED` (the default: formulas, dates and numbers are parsed as if typed) or `RAW` |
| `google_sheets/values.append@1` | Add `values` as new rows after the last row of the table in `range`. `insert_data_option` is `INSERT_ROWS` (the default) or `OVERWRITE` |
| `google_sheets/values.clear@1` | Empty the values in a `range`, keeping formatting and the rows and columns themselves |
| `google_sheets/sheet.add@1` | Add a tab, optionally with a size in rows and columns |

`spreadsheet.create`, `values.update`, `values.append`, `values.clear` and `sheet.add` change spreadsheets, so triggered runs treat them as mutating actions. `values.append` is not idempotent: running it twice appends twice.

A cell value is a string, a number, a boolean or `null` (an empty cell). Rows may be of different lengths, and Google leaves trailing empty cells off what it returns.

## Example: log each result as a row

```yaml
name: log-result
description: Append a row to the results sheet
entry: [log]

nodes:
  - id: log
    type: action
    uses: google_sheets/values.append@1
    with:
      spreadsheet_id: 1BxiMVs0XRA5nFMdKvBdBZjgmUUqptlbs74OgvE2upms
      range: Results
      values:
        - ["2026-12-01", "deploy", "ok"]
```
