# Forge Logo React Experiment

A standalone ReactJS/Vite design experiment for a minimalist Forge logo. The project contains no external assets; the mark is drawn as scalable inline SVG in React and presented with CSS for review at app-icon, lockup, monochrome, and small sizes.

## Concept

Forge is positioned as a crutch and harness for LLMs: infrastructure that helps the model create production-ready applications from day 0. The mark therefore avoids a generic hammer, flame, or chat shape. It uses an engineered support frame that forms a restrained `F`, with a hot center pin held by the frame.

The intended read is: Forge is the structure around the generative process, not the end-user interface to the model. The system holds, aligns, and tempers the build until it is ready to ship.

## Geometry

- The left upright is a load-bearing rail, representing the harness and scaffolding role.
- The top and middle beams create the `F` silhouette while reading as production support members.
- The bottom trapezoid-like foot references an anvil without becoming an illustrative anvil icon.
- The center diamond is the hot pin: the one active forging point where raw generation becomes a stable app.
- The open right side keeps the shape memorable and legible at favicon or dock-icon sizes.
- The large presentation includes subtle blueprint guide lines; they are contextual, not required for the core mark.

## Colors

- `#0A0F14` Carbon: app-icon field and serious developer-tool surface.
- `#E7EDF2` Forged Steel: primary mark color for high contrast and small-size readability.
- `#8494A3` Tempered Edge: gradient depth that gives the rails weight without adding extra shapes.
- `#FF7A2F` Hot Pin: controlled forge heat, used only as the activation point.
- `#5FA8FF` Blueprint Blue: subtle construction-guide accent in the presentation layer.

## How It Maps To Forge

The logo presents Forge as a supporting production apparatus. The structural `F` is the crutch/harness around the model, the anvil foot suggests readiness and durability, the blueprint guides suggest scaffolding, and the hot pin suggests transformation from prompt output into production-grade software. The minimal geometry keeps it serious, scalable, and suitable as an app icon or standalone brand mark.

## View Locally

```bash
cd design-experiments/forge-logo-react
npm install
npm run dev
```

Then open the Vite URL shown in the terminal.

For a production check:

```bash
npm run build
npm run preview
```
