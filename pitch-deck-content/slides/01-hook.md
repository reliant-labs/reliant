# You stopped writing code. Now you babysit the AI.

You stopped writing code. Now you babysit the AI.

---
**Speaker Notes:**
Everyone in this room got sold the same promise: the AI writes the code, you go do something that matters more. So how's that going? Most of us are reviewing diffs at midnight and retyping the same prompt three different ways to get one function right. Cursor and Claude Code made writing code almost free. Driving them still costs you every prompt, every diff, every test. That's the gap we're here to talk about.
