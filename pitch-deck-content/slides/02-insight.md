# Writing code got cheap. Verifying it did not.

**Generation → zero**
60+ model providers. Bring your own key. No lock-in. The model layer is a commodity, and it keeps getting cheaper.

**Verification → still yours**
Orchestration, determinism, checking every diff. A human signs off on the output. That's where the cost, and the value, moved.

Vibe coding was the demo. Vibe engineering is the job.

---
**Speaker Notes:**
So this is the root cause behind that midnight-diff feeling. The generation side collapsed — there are 60-plus providers now, you bring your own key, nobody's locked in, and the price keeps falling. What didn't get cheap is being sure the code is right. Orchestrating the agents, making runs repeatable, actually verifying the output — that's still a person, every time. That's the shift we're betting on: the demo was vibe coding, the job is vibe engineering.
