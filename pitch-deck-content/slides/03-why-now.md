# Agents can finally execute. Nothing makes them reliable.

**2021** — Copilot ships autocomplete
**2023** — GPT-4, Claude: multi-step planning
**2023** — Cursor: agents edit real repos
**2025** — Claude Code: agents run full tasks
**Now** — Models commoditized. Orchestration and determinism missing.

---
**Speaker Notes:**
So the reason we're building this now and not two years ago: the agents can actually do the work now. Back in 2021 it was autocomplete. By 2023 they could plan a multi-step change, and Cursor let them touch real repos. This year Claude Code will take a whole task start to finish. The models themselves are basically a commodity at this point — everybody's running the same loop against the same handful of providers. What nobody built is the layer that decides what runs when and makes the same input give you the same result twice. That's the gap, and it only opened up once the agents got good enough to trust with real execution. On adoption — I want to be straight with you, we don't have the market sizing pulled together yet, so I'm not going to throw a number on the screen I can't back up.
