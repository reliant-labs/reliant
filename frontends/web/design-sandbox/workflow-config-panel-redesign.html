Design Notes

Pattern: Same as Chat Input Popover

  • Uses the same visual language: dark panel, inline fields, section labels, mode pill groups, drill-in rows.
  • Sections replace the old category-divider approach with labeled groups.
  • CEL toggle on fields that support expressions — same pattern as current.
  • Collapsible param groups for nested/group inputs (implementer, reviewer, model).

Key Differences from Chat Popover

  • Config panel is a side panel, not a dropdown popover — wider (380px), persistent, scrollable.
  • Tab bar (Config / Thread / Inject / Advanced / Outputs) stays — it's the right separation.
  • Node identity in header with type icon, name, and ID (click-to-rename).
  • More fields visible — workflow builder users need to see everything. No aggressive hiding.

call_llm: Two Options

  • Option A (Sectioned): Model / Prompt / Tools as distinct sections with labels. Cleaner for complex configs. Each section is self-contained.
  • Option B (Compact): Everything flat with divider lines. Fewer headers, more vertical density. Tools as a drill-in row. Better for simple configs.
  • Recommendation: Option A for the builder (users need clarity). Option B style for the chat input popover (users need speed).

Top-Level Inputs: Two Options

  • Option A (agent.yaml): Simple workflow with ungrouped params + one model group. Shows the "Display" section (ui hints) — useful for workflow authors.
  • Option B (parallel-compete.yaml): Complex workflow with multiple nested groups, each with their own preset. Collapsed groups show preset badge + param count.
  • Group headers show the preset badge when a preset is selected — important visual signal.

Passthrough Params

  • When a workflow step passes inputs through via CEL ({{inputs.system_prompt}}), the field shows in a monospace CEL style.
  • The CEL toggle badge turns purple when active — same as current implementation.
  • Users can toggle between literal value and CEL expression on any field.

Router Candidates

  • Card-based list with workflow ref, preset, and description per candidate.
  • Add/remove with dashed "add" button at bottom.
  • Keeps the existing card pattern but with tighter spacing and better typography.
